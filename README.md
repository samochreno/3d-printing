# 3D printing

3D-printing files and operating context for a custom TEVO Tarantula.

## Layout

- `AGENTS.md` — printer configuration, material preferences, and safe operating context.
- `models/calibration/` — reusable STL calibration models.
- `gcode/calibration/` — printer-ready calibration G-code.

G-code is tied to the printer profile and should be reviewed before it is reused after a material or machine-setting change.
